🔐 Authentication

LensLink uses Laravel Sanctum for stateless token-based authentication. All protected routes require a valid Bearer token in the Authorization header.

1
Register or Login
Call POST /api/register or POST /api/login with your credentials. A Sanctum Bearer token is returned in the response.
2
Store the Token
Save the data.token value from the response. This is your personal access token valid until revoked.
3
Send with Every Request
Include the token in the Authorization header for all protected endpoints.
Authorization Header
JSON
Authorization: Bearer {your_token_here} Accept: application/json Content-Type: application/json
Postman tip: Set the token as a collection variable {{token}} and use it in the Authorization tab (Bearer Token type) across all requests.
👥 Roles & Permissions

Every user is assigned one of three roles at registration. The role determines what endpoints are accessible.

🔧
Admin
role_id: 1
Full access including admin-only endpoints such as /admin-stats. Requires auth:sanctum + role.admin middleware.
📸
Photographer
role_id: 2
Can manage their own posts, gallery, albums, images, and receive bookings from clients.
🙋
Client
role_id: 3
Can browse photographers, create bookings, like/comment on posts, and send messages.
⚠️ Error Handling

All API responses use a consistent JSON structure. HTTP status codes accurately reflect the result.

Standard Error Response
JSON
{ "status": "error", "message": "Validation failed.", "errors": { "email": ["The email field is required."] } }
Status CodeMeaningWhen
200OKSuccessful GET / action
201CreatedResource created (register, booking, post)
400Bad RequestMissing or malformed query parameters
401UnauthenticatedNo token or invalid/expired token
403ForbiddenAuthenticated but insufficient role
404Not FoundResource does not exist
422UnprocessableValidation failed (missing/invalid fields)
429Too Many RequestsRate limit exceeded
500Server ErrorUnexpected internal error
🚦 Rate Limiting

Authentication endpoints are protected with Laravel's built-in throttle middleware to prevent brute-force attacks.

throttle:10,1 — Auth endpoints (/register, /login, /auth/firebase) are limited to 10 requests per minute per IP. Exceeding this returns a 429 response with a Retry-After header.
429 Response Example
JSON
HTTP/1.1 429 Too Many Requests Retry-After: 42 Content-Type: application/json {"message": "Too Many Attempts."}
