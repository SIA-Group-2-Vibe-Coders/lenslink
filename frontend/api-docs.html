LensLink API Reference v1

Welcome to the LensLink API reference portal! LensLink is a premium, visual marketplace and social ecosystem designed to connect professional photographers with prospective clients seamlessly. Our backend is powered by Laravel 11 running on PHP, featuring secure JWT/Session integration via Laravel Sanctum, real-time chats with Pusher, Stripe payments, and secure high-performance image uploads to Cloudinary.

Use the toggles in the header to switch between Local Dev and Production. You can filter the left sidebar using the real-time search bar.

Security & Authentication Shield

Most interactive and transactional endpoints require authentication. LensLink utilizes Laravel Sanctum to issue secure API bearer tokens. Once a user logs in successfully, you must include the token in the headers of all subsequent requests.

Authorization: Bearer <YOUR_API_TOKEN>
POST /register Public Route

Creates a new user account in LensLink. Users can register either as a client (to book sessions) or a photographer (to publish galleries and receive bookings).

Request Body Parameters
Parameter Type Description
namerequired string The full name of the user. Min length: 3.
emailrequired string A valid, unique email address.
passwordrequired string Min length: 8 characters. Must match confirmation.
password_confirmationrequired string Repeated password for validation.
rolerequired string Must be either "client" or "photographer".
POST /login Public Route

Authenticates the user using email and password, returning an active API Token and essential user profile objects.

Request Body Parameters
Parameter Type Description
emailrequired string The user's registered email address.
passwordrequired string The user's password.
POST /auth/firebase Public Route

Exchanges a Firebase Identity Provider JWT (returned from social logins like Google Sign-In) for a secure, permanent LensLink Sanctum API Token.

Request Body Parameters
Parameter Type Description
tokenrequired string The raw Google/Firebase ID JWT token.
GET /profile Bearer Token Required

Retrieves the fully populated profile structure of the currently authenticated user, including role details and settings.

POST /profile/update Bearer Token Required

Updates profile parameters. If the authenticated user is a photographer, this route allows configuring pricing, specialties, and business parameters.

Request Body Parameters (Multipart Form-Data supported)
Parameter Type Description
nameoptional string Update the display name.
biooptional string A brief biography.
specialtyoptional string E.g., "Wedding", "Portrait", "Landscape".
locationoptional string Primary operating city.
rateoptional numeric Hourly booking fee in USD.
profile_pictureoptional file Image file (jpeg, png, webp) up to 2MB. Uploaded directly to Cloudinary.
POST /logout Bearer Token Required

Revokes the active Sanctum Token and invalidates the user session instantly.

GET /photographers Public Route

Retrieves a filtered, searchable listing of professional photographers registered on the platform.

Query Parameters
Parameter Type Description
searchoptional string Fuzzy match against name, specialty, or bio.
locationoptional string Fuzzy operating location string.
GET /photographers/{id} Public Route

Retrieves standard detailed public metadata about a photographer, including pricing, specialties, location coords, reviews, and linked public albums.

GET /search/location Public Route

Proxies and interfaces with Google Maps API to search operating coordinates and location details by dynamic string search query.

Query Parameters
Parameter Type Description
queryrequired string Address or city name search query.
GET /gallery Public Route

Retrieves a combined feed of active, public media galleries created by photographers.

GET /albums Public Route

Lists public albums across all galleries. Useful for general exploration screens.

GET /images Public Route

Fetches a direct listing of public imagery, fully resolved with Cloudinary links.

POST /gallery Bearer Token Required

Creates a parent gallery entity to categorize multiple sub-albums.

Request Body Parameters
Parameter Type Description
titlerequired string E.g., "Corporate & Branding". Max: 255.
descriptionoptional string Contextual summary of the gallery.
POST /albums Bearer Token Required

Creates an Album container tied to a specific Gallery.

Request Body Parameters
Parameter Type Description
gallery_idrequired integer ID of the parent gallery.
titlerequired string The sub-album title.
descriptionoptional string Details of the photoshoot album.
POST /images/upload Bearer Token Required

Directly uploads an image binary payload. Handles optimization and uploads directly to Cloudinary CDN, returning a permanent optimized asset URL.

Request Body Parameters (Multipart)
Parameter Type Description
album_idrequired integer The album target to append the image to.
imagerequired file Image asset binary file up to 5MB size limit.
POST /images/archive Bearer Token Required

Marks a active image as archived (soft hidden from public screens) without deleting database relations permanently.

Request Body Parameters
Parameter Type Description
image_idrequired integer The database ID of the image to archive.
GET /posts Public Route

Fetches the social interaction feed, displaying structured posts created by photographers with likes, comments counts, and media URLs.

POST /posts Bearer Token Required

Creates a new feed post in LensLink. Includes support for uploading custom cover photos.

Request Body Parameters
Parameter Type Description
bodyrequired string Main text body of the social post.
imageoptional file Optional post background/showcase photo up to 2MB.
DELETE /posts/{id} Bearer Token Required

Deletes the requested post permanently. The user must be the original author of the post.

POST /posts/{id}/like Bearer Token Required

Toggles a like status on the target post for the currently authenticated user.

POST /posts/{id}/comment Bearer Token Required

Adds a textual commentary reply to a active social feed post.

Request Body Parameters
Parameter Type Description
bodyrequired string The reply statement content text.
GET /conversations Bearer Token Required

Lists all unique chat dialogue channels active for the authenticated user, resolving the counterparty's profiles and latest messages.

GET /messages Bearer Token Required

Fetches the detailed chronological chat history of a active dialog with another counterparty.

Query Parameters
Parameter Type Description
user_idrequired integer The database ID of the chat counterparty.
POST /messages Bearer Token Required

Dispatches a direct chat message to another user. Dispatches real-time client side refresh signals through integrated Pusher channels automatically.

Request Body Parameters
Parameter Type Description
receiver_idrequired integer Recipient user ID.
messagerequired string The text body of the chat.
POST /bookings/intent Bearer Token Required

Generates a Stripe Payment Intent clientSecret payload based on booking parameters to process dynamic credit card checkouts on the frontend.

Request Body Parameters
Parameter Type Description
photographer_idrequired integer The targeted photographer user ID.
amountrequired numeric Amount in cents (e.g. 5000 for $50.00).
POST /bookings Bearer Token Required

Creates a active pending photographer reservation record on LensLink.

Request Body Parameters
Parameter Type Description
photographer_idrequired integer Photographer ID.
booking_daterequired string Date/time in ISO-8601 or YYYY-MM-DD standard format.
durationrequired integer Duration of the photoshoot in hours.
locationrequired string The address for the photoshoot.
notesoptional string Extra instructions or requirements.
GET /bookings Bearer Token Required

Retrieves a customized list of active booking sheets. Clients see their outbound booking requests; Photographers see inbound inquiries.

GET /bookings/{id} Bearer Token Required

Retrieves complete structural detail of a single reservation record (pricing calculation, address coordinate indicators, notes, statuses).

PATCH /bookings/{id}/status Bearer Token Required

Allows a photographer to accept or reject an incoming reservation request.

Request Body Parameters
Parameter Type Description
statusrequired string Must be either "approved" or "rejected".
POST /bookings/{id}/pay Bearer Token Required

Pre-initiates booking invoice payment parameters for client approval.

POST /bookings/{id}/confirm Bearer Token Required

Validates and registers Stripe success transaction signals to transition the booking status to "paid".

Request Body Parameters
Parameter Type Description
payment_intent_idrequired string The validated Stripe Payment Intent token starting with pi_....
